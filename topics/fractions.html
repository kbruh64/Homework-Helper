Grade 3

Fractions.

A fraction is a way to name part of a whole. The bottom number is how many pieces it is cut into; the top is how many you have.

What you’ll learn

The skills inside this topic.

  • 01
    Identify numerator and denominator

    Top is how many. Bottom is the size of each piece.

  • 02
    Place fractions on a number line

    Between 0 and 1, evenly spaced.

  • 03
    Find equivalent fractions

    Different names for the same amount.

  • 04
    Compare fractions with the same top or bottom

    When one part is the same, comparing is easy.

Try these

Quick examples

Read the question, think it through, then peek at the answer.
Which is larger: 1/3 or 1/4?
1/3 — fewer pieces means each one is bigger.
Is 2/4 the same as 1/2?
Yes — same amount, different names.
Place 3/8 on a number line from 0 to 1.
Just under halfway.
Common slip-ups

The mistakes most kids make here.

Knowing the trap is half of avoiding it. If you catch yourself doing one of these, slow down — it just means the concept is still settling.

01

Bigger bottom means bigger fraction

1/8 is smaller than 1/4, even though 8 > 4.

02

Adding tops and bottoms

Saying 1/2 + 1/2 = 2/4 instead of 1.
