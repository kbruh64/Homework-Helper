Grade 4

Patterns & Rules.

Generating a pattern from a rule, finding a rule from a pattern, and solving for a missing number in a simple equation.

What you’ll learn

The skills inside this topic.

  • 01
    Generate a pattern from a rule

    Apply the rule again and again.

  • 02
    Find features of a pattern

    Always even? Always odd? Increasing fast?

  • 03
    Read input/output tables

    A rule turns each input into its output.

  • 04
    Solve equations with a missing number

    8 × ? = 56 — what fills the blank?
