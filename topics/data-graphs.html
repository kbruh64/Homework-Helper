Grade 3

Data & Graphs.

Collecting data, drawing it as a chart, and reading what the chart says back. Bar graphs and pictographs are the workhorses.

What you’ll learn

The skills inside this topic.

  • 01
    Read a bar graph

    Match each bar to its label and check the scale.

  • 02
    Read a pictograph

    Each picture stands for a number — use the key.

  • 03
    Make a tally chart

    One mark per item. Cross every fifth one.

  • 04
    Answer questions from a graph

    How many more, how many fewer, what was the total.

Common slip-ups

The mistakes most kids make here.

Knowing the trap is half of avoiding it. If you catch yourself doing one of these, slow down — it just means the concept is still settling.

01

Ignoring the key on a pictograph

Counting symbols without checking what each one is worth.

02

Misreading a scale that skips numbers

A bar graph going 0, 5, 10, 15 — not 0, 1, 2.
