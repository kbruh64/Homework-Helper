Grade 3

Patterns.

Numbers and shapes that repeat by a rule. The trick is figuring out the rule from a few terms — then using it to predict what comes next.

What you’ll learn

The skills inside this topic.

  • 01
    Spot the rule in a number pattern

    Add 5? Times 2? Look at the gap.

  • 02
    Continue a pattern

    Apply the rule to find the next few terms.

  • 03
    Recognize shape and color patterns

    AABB, ABCABC, and so on.

  • 04
    Read a simple input/output table

    A rule turns each input into its output.

Quick examples

Read the question, think it through, then peek at the answer.
Continue: 3, 6, 9, 12, ___

Common slip-ups

The mistakes most kids make here.

Knowing the trap is half of avoiding it. If you catch yourself doing one of these, slow down — it just means the concept is still settling.

01

Picking the wrong rule from too few terms

Two terms is not enough — check at least three.

02

Continuing by gut

Always test the rule against the given terms first.
