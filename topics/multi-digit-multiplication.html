Grade 4

Multi-Digit Multiplication.

Multiplying 2, 3, and 4-digit numbers. The standard algorithm and the area model both work — pick the one that helps you see it.

What you’ll learn

The skills inside this topic.

  • 01
    Multiply a multi-digit number by a 1-digit number

    Build up from times tables you already know.

  • 02
    Multiply two 2-digit numbers

    Each digit on top times each digit on bottom — then add.

  • 03
    Use the area model

    Break each number into its place values and multiply each piece.

  • 04
    Estimate to check

    Round, multiply roughly, see if your answer is in range.
